1. The Heading Tag (<h1> to <h6>)

Use Case: Used to define headings. <h1> is the most important.

Code Example:

<h1>This is a Main Heading</h1>
<h2>This is a Subheading</h2>

Result:

This is a Main Heading

This is a Subheading

More Info: W3C Headings

2. The Paragraph Tag (<p>)

Use Case: Defines a block of text.

<p>This is a paragraph showing text content.</p>

Result:

This is a paragraph showing text content.

More Info: W3C Paragraph

3. The Anchor Tag (<a>)

Use Case: Creates a hyperlink to link to other pages or resources.

<a href="index.html" title="Go back to the homepage">Go Home</a>

Result:

Go Home

More Info: W3C Anchor

4. The Image Tag (<img>)

Use Case: Embeds an image into the document. Requires src (source) and alt (alternative text).

<img src="img/logo_html.png" alt="HTML Logo" width="50">

Result:

More Info: W3C Image

5. The Unordered List Tag (<ul> and <li>)

Use Case: Creates a list of items, typically rendered as bullet points.

<ul>
  <li>Item One</li>
  <li>Item Two</li>
</ul>

Result:

  • Item One
  • Item Two

More Info: W3C List
