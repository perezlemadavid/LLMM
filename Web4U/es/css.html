1. Propiedad: color

Caso de Uso: Establece el color de primer plano del texto.

Ejemplo de Código:

#color-example {
  color: #2980b9; /* Azul */
}

Resultado:

Este texto es azul.

Más Información: W3C color

2. Propiedad: background-color

Caso de Uso: Establece el color de fondo de un elemento.

#bg-color-example {
  background-color: #f1c40f; /* Amarillo */
}

Resultado:

Este elemento tiene un fondo amarillo.

Más Información: W3C background-color

3. Propiedad: font-size

Caso de Uso: Establece el tamaño de la fuente.

#font-size-example {
  font-size: 20px;
}

Resultado:

Este texto tiene 20 píxeles de tamaño.

Más Información: W3C font-size

4. Propiedad: border

Caso de Uso: Establece el grosor, estilo y color del borde de un elemento.

#border-example {
  border: 2px solid #e74c3c; /* Borde rojo sólido */
}

Resultado:

Este elemento tiene un borde rojo sólido.

Más Información: W3C border

5. Propiedad: margin

Caso de Uso: Crea espacio alrededor de los elementos, fuera de cualquier borde definido.

#margin-example {
  margin-left: 50px; /* Margen izquierdo */
}

Resultado:

Este elemento tiene un margen de 50px a la izquierda.

Más Información: W3C margin
