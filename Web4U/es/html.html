1. Etiqueta de Encabezado (<h1> a <h6>)

Caso de Uso: Se utiliza para definir encabezados. <h1> es el más importante.

Ejemplo de Código:

<h1>Este es un Encabezado Principal</h1>
<h2>Este es un Subtítulo</h2>

Resultado:

Este es un Encabezado Principal

Este es un Subtítulo

Más Información: W3C Encabezados

2. Etiqueta de Párrafo (<p>)

Caso de Uso: Define un bloque de texto.

<p>Este es un párrafo que muestra contenido de texto.</p>

Resultado:

Este es un párrafo que muestra contenido de texto.

Más Información: W3C Párrafo

3. Etiqueta Ancla (<a>)

Caso de Uso: Crea un hipervínculo para enlazar a otras páginas o recursos.

<a href="index.html" title="Volver a la página principal">Ir a Inicio</a>

Resultado:

Ir a Inicio

Más Información: W3C Ancla

4. Etiqueta Imagen (<img>)

Caso de Uso: Incrusta una imagen en el documento. Requiere src (origen) y alt (texto alternativo).

<img src="../img/logo_html.png" alt="Logotipo HTML" width="50">

Resultado:

Más Información: W3C Imagen

5. Etiqueta Lista Desordenada (<ul> y <li>)

Caso de Uso: Crea una lista de elementos, normalmente mostrados con puntos o viñetas.

<ul>
  <li>Elemento Uno</li>
  <li>Elemento Dos</li>
</ul>

Resultado:

  • Elemento Uno
  • Elemento Dos

Más Información: W3C Lista
