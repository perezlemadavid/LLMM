1. Etiqueta Rectángulo (<rect>)

Caso de Uso: Se utiliza para crear una forma de rectángulo o cuadrado.

Ejemplo de Código:

<svg width="150" height="100">
  <rect width="100" height="80" x="25" y="10" 
        style="fill:blue; stroke:red; stroke-width:3" />
</svg>

2. Etiqueta Círculo (<circle>)

Caso de Uso: Se utiliza para crear una forma circular basada en un punto central y un radio.

<svg width="150" height="100">
  <circle cx="75" cy="50" r="40" 
          stroke="green" stroke-width="4" fill="yellow" />
</svg>

Resultado:

Más Información: W3C <circle>

3. Etiqueta Línea (<line>)

Caso de Uso: Se utiliza para dibujar una línea recta entre dos puntos.

<svg width="150" height="100">
  <line x1="10" y1="10" x2="140" y2="90" 
        style="stroke:rgb(255,0,0); stroke-width:2" />
</svg>

Resultado:

Más Información: W3C <line>

4. Etiqueta Texto (<text>)

Caso de Uso: Se utiliza para dibujar texto dentro del gráfico SVG.

<svg width="200" height="50">
  <text x="10" y="30" fill="purple" 
        font-size="20">Hola SVG</text>
</svg>

Resultado:

Más Información: W3C <text>

5. Etiqueta Ruta (<path>)

Caso de Uso: Se utiliza para definir formas complejas usando líneas y curvas arbitrarias. Es el elemento más potente.

<svg width="150" height="100">
  <path d="M 20 20 L 100 20 L 60 80 Z" 
        stroke="black" fill="red" stroke-width="2"/>
</svg>
