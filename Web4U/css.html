1. Property: color

Use Case: Sets the foreground color of text.

Code Example:

#color-example {
  color: #2980b9; /* Azul */
}

Result:

This text is blue.

More Info: W3C color

2. Property: background-color

Use Case: Sets the background color of an element.

#bg-color-example {
  background-color: #f1c40f; /* Amarillo */
}

Result:

This element has a yellow background.

More Info: W3C background-color

3. Property: font-size

Use Case: Sets the size of the font.

#font-size-example {
  font-size: 20px;
}

Result:

This text is 20 pixels large.

More Info: W3C font-size

4. Property: border

Use Case: Sets the thickness, style, and color of an element's border.

#border-example {
  border: 2px solid #e74c3c; /* Borde rojo sólido */
}

Result:

This element has a solid red border.

More Info: W3C border

5. Property: margin

Use Case: Creates space around elements, outside of any defined borders.

#margin-example {
  margin-left: 50px; /* Margen izquierdo */
}

Result:

This element has a 50px margin on the left.

More Info: W3C margin
