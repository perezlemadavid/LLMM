1. The Rectangle Tag (<rect>)

Use Case: Used to create a rectangle or square shape.

Code Example:

<svg width="150" height="100">
  <rect width="100" height="80" x="25" y="10" 
        style="fill:blue; stroke:red; stroke-width:3" />
</svg>

Result:

More Info: W3C <rect>

2. The Circle Tag (<circle>)

Use Case: Used to create a circular shape based on a central point and radius.

<svg width="150" height="100">
  <circle cx="75" cy="50" r="40" 
          stroke="green" stroke-width="4" fill="yellow" />
</svg>

Result:

More Info: W3C <circle>

3. The Line Tag (<line>)

Use Case: Used to draw a straight line between two points.

<svg width="150" height="100">
  <line x1="10" y1="10" x2="140" y2="90" 
        style="stroke:rgb(255,0,0); stroke-width:2" />
</svg>

Result:

More Info: W3C <line>

4. The Text Tag (<text>)

Use Case: Used to draw text within the SVG graphic.

<svg width="200" height="50">
  <text x="10" y="30" fill="purple" 
        font-size="20">Hello SVG</text>
</svg>

Result:

More Info: W3C <text>

5. The Path Tag (<path>)

Use Case: Used to define complex shapes using arbitrary lines and curves. It's the most powerful element.

<svg width="150" height="100">
  <path d="M 20 20 L 100 20 L 60 80 Z" 
        stroke="black" fill="red" stroke-width="2"/>
</svg>
